\begin{abstract}
This paper comparatively evaluates position- and vision-aided beam prediction
using camera images, GPS position, drone height, and distance information.
Position-only prediction achieves 57.59\% Top-1 accuracy, which increases to
74.19\% when height and distance are included. The refined image model achieves
88.32\% Top-1 accuracy, exceeding the directly comparable reference result by
2.00 percentage points. A comparison of the experimental setups identifies
differences in beam-class definition, dataset split, model architecture, batch
size, and missing-data treatment. The results therefore demonstrate consistent
modality-level findings under a modified setup rather than an exact
reproduction of the reference study.
\end{abstract}
